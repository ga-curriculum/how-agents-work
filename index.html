PERCEIVE — The agent reads its environment. For a modern LLM agent, this means receiving a user message, an API event, a scheduled trigger, or a tool result. Without perception there is nothing to act on — this is the entry point of every loop iteration.
Why the Loop Matters
🔁

Correct Mistakes

If the first action fails, the agent tries a different approach instead of stopping.

🌊

Adapt to Change

Environment shifts require re-evaluation and new plans — only possible through iteration.

🎯

Achieve Autonomy

Multi-step goal pursuit requires continuous operation — not one-shot text generation.

📈

Learn from Results

Feedback from actions informs better decisions. The loop transforms prediction into behavior.

Section 02

Four Classical Agent Types

From classical AI theory (Russell & Norvig). Click each card to explore the architecture. Modern LLM agents are hybrid systems combining elements from all four.

01
⚡

Reactive Agents

Stimulus → Response. No memory, no planning.

Tap to expand ↓

No internal model of the world. Immediate, deterministic response to input. Example: A thermostat — temperature drops below threshold → turn on heater. No memory, no learning, no planning. Fast and reliable but brittle — can't handle anything outside its trigger conditions.
02
🎯

Goal-Based Agents

Compare state vs. goal. Introduce planning.

Tap to expand ↓

Evaluate actions based on: "Does this move me closer to the goal?" Goal-based agents introduce planning — the ability to evaluate future states and select actions that advance toward a defined objective. First type capable of genuine multi-step reasoning.
03
⚖️

Utility-Based Agents

Optimize trade-offs. Maximize a utility function.

Tap to expand ↓

Instead of binary goals, utility-based agents optimize trade-offs. Example: minimize cost ⚖️ maximize speed. They find the optimal balance — not just "yes/no" on a single goal. This is the foundation of modern recommendation and routing systems.
04
🧬

Learning Agents

Update model from experience. Adapt over time.

Tap to expand ↓

Four components: Performance Element (selects actions), Learning Element (improves from feedback), Critic (evaluates outcomes), Knowledge Base (stores experience). Most advanced classical type — closest to modern LLM agents.
